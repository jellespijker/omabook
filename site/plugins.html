Plugins

Plugins add formats, panels, commands and whole ways of using the library. Omabook lists them itself: press P then I, or run omabook plugin search. This page is built from the same lists.

How they are found

The registry
share/omabook/plugins.json in Omabook’s repository: plugins someone asked to have listed, with their permissions and the Omabook they need. Reviewed.
GitHub, by topic
Repositories with the topic omabook-plugin. Each one’s plugin.json is fetched and checked; archived repositories are left out. Not reviewed: read what a plugin asks before you install it.
Rebuilt daily
The site’s workflow rebuilds this page every day, so a plugin listed today is here tomorrow. Nothing runs in your browser.

Showcase

Storyteller

Writes you a book. Say what you are in the mood for: it builds a world, invents the people, plans a plot with twists seeded before they pay off, and writes chapter one. The next is written while you read the one before. Everything it writes is original by rule. It is also a worked example of a plugin.

omabook plugin add storyteller

Notebooks

Notebooks of pages on paper: lined, squared, dotted, music staves or Cornell. Write with a pen, type, add pictures and recordings. Handwriting is read, recordings are transcribed, and a page links to the passage you were reading. Export as PDF or Markdown.

omabook plugin add notebooks
