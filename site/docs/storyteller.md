# Storyteller

**Storyteller** writes an original book for you, chapter by chapter, as you read it. Start one from the shelf; steer it, ask the author, or branch it.

## Install

Install it from *Find plugins* (`I` in the plugin manager), or in a terminal with `omabook plugin add storyteller`. It comes from [jellespijker/omabook-storyteller](https://github.com/jellespijker/omabook-storyteller) (MIT), asks for `files` and `http` permissions, and needs Omabook 0.1.4 or newer.

## How it writes

Say what you are in the mood for: Storyteller builds a world, invents the people, plans a plot with twists seeded before they pay off, and writes chapter one. The next chapter is written while you read the one before. Everything it writes is original by rule.

## Format and plugin example

Storyteller saves books in the `.story` format and registers a format, launcher, command, panel and hook. It is also a worked example of a full script plugin; see [Plugins](plugins.html).
