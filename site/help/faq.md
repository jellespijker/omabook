# Questions

**Does it change my files?**

No. Added books are copied into the library; the file you added is never touched.

**Does my reading leave the computer?**

Only to the AI you chose, and only what the question needs. Hosted providers are used only where you allowed them.

**Does the page track me?**

No. This site is static: no cookies, no analytics, no third-party scripts.
