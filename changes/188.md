- Sync a computer with its hub, by hand (#188): `omabook sync <hub>` (or `omabook hub sync`, with the one hub this computer is linked to) is the sync two computers do, through the hub's session, never a shell; `--dry-run` shows first what it would do, on either side, and changes nothing. The hub writes only through its daemon, and takes a moment snapshot first. The window's Sync goes through the hub when the computer it names is one. A computer and a hub whose libraries are of different formats don't sync, and say which Omabook to update. Computers still sync with each other directly, as before.
