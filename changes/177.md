- A Phones and e-readers panel (#177), from the settings and the library's menu (Shift+D): whether the library is served, by whom (this window, the background service, or `omabook serve` in a terminal), where (this computer only, the home network, or the tailnet), on which port and how many devices asked lately; the catalog's address (by this computer's name on the tailnet as well as by its number), the user name and the password, each with a Copy button, and QR codes to scan: of the address, and of the address with the password in it for an app that takes none. It names the apps that read it and where each adds a catalog: KOReader (on Android, Kobo, PocketBook and Kindle), Librera and Moon+ Reader. KOReader's sync server address comes as a QR code too, and the whole library or one collection can be served.
- Serving with the window closed: a switch sets up a systemd user service of your own (`omabook-serve.service`, no administrator needed) that serves from login on, and the window leaves serving to it.
- `omabook serve` while the window (or the background service) serves already says so and prints where devices find it, instead of failing with "address already in use"; a port taken by another program names that program.
