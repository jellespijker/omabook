- A fallback for each AI capability, used only when its server can't be reached at all, never when it answers with an error (#174). Meaning, handwriting, speech to text and reading aloud fall back to this computer by themselves (Ollama at localhost, voxtype or whisper.cpp, Piper or speech-dispatcher), or to another server chosen in their row, with its address, key and model. Answers fall back only where you choose a fallback for them, and say who answered. Quick work waits for its server instead: the knowledge graph catches up once the server is back, and nothing is lost. A fallback that is someone else's computer needs its own allowance, and nothing falls back with the AI off. Meaning's fallback is always asked for the same model, so a book indexed on one server is searched on either. While a fallback is in use, the row and Find say so ("the server can't be reached"); a server that doesn't answer is tried for a second at most and then left alone for half a minute, so nothing hangs, and Omabook goes back to it by itself once it answers. Each row's fallback has its own Test, and plugins see in `ai.status` whether the fallback answered (`fallback`, `first`).
