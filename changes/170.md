- Each row of the AI page its own (#170): handwriting can be read by a server of its own (its address, its key in the keyring and its model, in the Handwriting row; `recognition.ink_url`), such as Ollama on another computer, and keeps the AI server where none is given, so today's setup carries on as it was. Under every row a line says what Omabook uses it for (quick work builds the knowledge graph, tidies the library, finds a book's details, suggests the companion's questions and understands the voice commands Omabook doesn't know itself; answers are the companion, catch-ups and asking about your library; and so on), and the knowledge graph's Build says it is the model for quick work that reads. Each row has a Test (or T on the row), which sends one small real request through exactly that row's provider, server, key and model: a two-word reply, a tiny drawn word read back, a short clip heard, a sentence said, or one vector. It shows what came back and how long it took, or why not: no route, a refused key, the model not found, no answer in time, hosted not allowed. A test that would go to someone else's computer where the row doesn't allow it asks first, and allows nothing after it; with the AI off there is no Test.
