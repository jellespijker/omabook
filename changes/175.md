- Find a model for any AI capability beyond what its server has (#175): "Find a Model…" in each row of the AI page, and where a missing model is reported, searches Ollama's library and Hugging Face for models that can do it (vision models for handwriting, embedding models for meaning, any that talk for answers and quick work; for speech, whisper.cpp's models and Piper's voices). Each shows its download size, the memory it needs and whether that fits this computer's free memory and graphics card (or that it can't be told for a server elsewhere), its licence, and whether it runs on someone else's computer. One press installs it onto the capability's Ollama server (Hugging Face's GGUF models as `hf.co/…`), or downloads a speech model where whisper.cpp and Piper keep theirs, chooses it, and tests it once. Nothing is searched until you search, only the words you typed and the kind of model go out, never a book or a note, and with the AI off nothing is searched. A model that runs on Ollama's computers is installed only where hosted is allowed for that capability.
