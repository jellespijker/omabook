- Importing a Calibre library no longer passes anything over in silence. A book Omabook can't take (no file in Calibre, files that are gone or can't be read, or only formats it doesn't take) is counted and named with the reason, by the window, the command line (`skipped` and `left_out` with `--json`; the exit code is 1) and the log (`omabook logs`). So are a format or cover that didn't come with a book, and a library that can't be read to its end.
